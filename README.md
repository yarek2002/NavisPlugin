# ClashManager

Плагин для **Autodesk Navisworks** (сборка ориентирована на **Navisworks 2021**, .NET Framework **4.8**, x64). На ленте появляется вкладка **ClashUnionManager** с инструментами для работы с **Clash Detective**: группировка, кластеризация, поиск наборов, менеджер коллизий и экспорт в 3D-форматы.

## Требования

- Установленный Navisworks с поддерживаемой версией API (в проекте — DLL из папки `ClashManager/libs/`).
- Скопированные в выходную папку плагина зависимости (в т.ч. при использовании экспорта — сборка **Navis3dExporter** и связанные DLL).

## Основные функции (уже подключены к ленте)

### Группировка по фрагментам

Выполняет группировку результатов по фрагментам (модуль `CollisionGrouper` / окно `MainView`).

### Группировка по кластерам

Запускает кластеризацию коллизий через `CollisionClusterPlugin` (`Clustering.MakeClusters()`).

### Перенести в подтверждено

После подтверждения в диалоге переносит коллизии в состояние, обрабатываемое логикой **MoveToConfirmed** (массовая смена статуса по заданным правилам плагина).

### Найти наборы

По **ровно двум** выделенным в модели элементам открывает окно поиска связанных поисковых наборов и правил Clash (`FindSearchSets`).

### Авто-группировка и кластеризация («волшебная палочка»)

Автоматическая группировка и кластеризация для тестов, где есть не сгруппированные результаты (исключая заданные «закрытые» статусы вроде Reviewed / Approved / Resolved). Реализация в `MagicWand`.

### Менеджер коллизий

Отдельное окно для просмотра и работы со списком тестов и коллизий: отбор, сортировка, поиск, смена статусов, синхронизация с активным окном Clash Detective, подготовка выбора для экспорта в GLB/glTF (совместимость с режимами Navis3dExporter).

### Авто-наименование

Окно настроек и применения автоматического наименования групп коллизий (`AutoNaming`).

### Экспорт GLB и glTF

Команды вызывают UI **Navis3dExporter** (`ExportWindow`): экспорт **всей модели**, **текущего выделения** или **всех групп коллизий** (в зависимости от выбранного режима в окне). Используется загрузка сборки через `Navis3dExporterAssemblyResolver`.

## Команды в коде, но без кнопки на текущей ленте

В обработчике `CollisionGrouperCommandHandler` зарегистрирована команда **CreateSearchSet** (создание поискового набора по одному выбранному элементу), однако в актуальном `AddinRibbon.xaml` для неё **нет** отдельной кнопки — запуск возможен только при добавлении элемента на ленту или вызове из другого кода.
