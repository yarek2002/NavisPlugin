# Автоматизация выгрузки отчетов из Navisworks

## Описание

Данная система автоматизации позволяет выполнить полный цикл обработки коллизий в Navisworks и выгрузить отчеты без ручного вмешательства.

## Функциональность

Автоматизация выполняет следующие шаги:

1. **Открытие файла NWF** - автоматически открывает указанный файл Navisworks
2. **Обновление тестов** - обновляет все тесты коллизий
3. **Автогруппировка и кластеризация** - запускает функцию "MagicWand" для автоматической группировки
4. **Авто-наименование** - запускает функцию авто-наименования групп коллизий
5. **Выгрузка отчета** - создает подробный отчет в текстовом формате
6. **Закрытие Navisworks** - автоматически закрывает приложение после завершения

## Использование

### Способ 1: Через интерфейс плагина

1. Откройте Navisworks с нужным файлом NWF
2. В ленте найдите вкладку "ClashUnionManager"
3. Нажмите кнопку "Автоматизация отчетов"
4. Выберите папку для сохранения отчета
5. Подтвердите запуск автоматизации

### Способ 2: Через PowerShell скрипт

```powershell
.\NavisworksAutomation.ps1 -NwfFilePath "C:\path\to\your\file.nwf" -OutputFolderPath "C:\path\to\output\folder"
```

#### Параметры PowerShell скрипта:

- `-NwfFilePath` (обязательный) - путь к файлу NWF для обработки
- `-OutputFolderPath` (обязательный) - папка для сохранения отчета
- `-TimeoutMinutes` (необязательный) - таймаут в минутах (по умолчанию 30)

## Структура файлов

### Созданные файлы:

1. **ClashManager/Automation/ReportAutomation.cs** - основной класс автоматизации
2. **ClashManager/Externals/ReportAutomationCmd.cs** - команда для запуска из интерфейса
3. **ClashManager/CollisionManager.cs** - обновлен для поддержки новой команды
4. **ClashManager/AddinRibbon.xaml** - обновлен для добавления кнопки
5. **NavisworksAutomation.ps1** - PowerShell скрипт для внешней автоматизации

### Выходные файлы:

- **ClashReport_YYYYMMDD_HHMMSS.html** - HTML отчет по коллизиям (по умолчанию)
- **ClashReport_YYYYMMDD_HHMMSS.txt** - текстовый отчет (альтернативный формат)
- **ClashReport_YYYYMMDD_HHMMSS.csv** - CSV отчет (альтернативный формат)
- **ClashReport_YYYYMMDD_HHMMSS.xml** - XML отчет (альтернативный формат)
- **automation_log.txt** - лог выполнения автоматизации

## Формат отчета

### HTML формат (по умолчанию)
Отчет экспортируется в HTML формате с табличным представлением, используя настройки из файла Navisworks. Содержит:

- **Сводную информацию**: общее количество тестов, групп и результатов
- **Детальные таблицы**: по каждому тесту с информацией о группах и их статусах
- **Цветовое кодирование**: статусы коллизий выделены разными цветами
- **CSS стили**: современный дизайн с адаптивной версткой

### Альтернативные форматы
- **TXT**: текстовый формат для простого просмотра
- **CSV**: для импорта в Excel или другие системы
- **XML**: структурированные данные для дальнейшей обработки

### Пример HTML отчета:
```html
<!DOCTYPE html>
<html lang='ru'>
<head>
    <title>Отчет по коллизиям</title>
    <style>/* CSS стили */</style>
</head>
<body>
    <div class='header'>
        <h1>Отчет по коллизиям</h1>
        <p><strong>Дата создания:</strong> 2024-01-15 14:30:25</p>
        <p><strong>Файл:</strong> MyProject.nwf</p>
    </div>
    <div class='summary'>
        <h2>Сводная информация</h2>
        <table>
            <tr><th>Параметр</th><th>Значение</th></tr>
            <tr><td>Общее количество тестов</td><td>5</td></tr>
            <tr><td>Общее количество групп</td><td>15</td></tr>
            <tr><td>Общее количество результатов</td><td>45</td></tr>
        </table>
    </div>
    <!-- Детальные таблицы по тестам -->
</body>
</html>
```

## Требования

- Navisworks Manage 2021 или новее
- Установленный плагин ClashManager
- PowerShell 5.0 или новее (для внешнего скрипта)

## Устранение неполадок

### Ошибка "Navisworks не найден"
Убедитесь, что Navisworks установлен в стандартном пути:
- `C:\Program Files\Autodesk\Navisworks Manage 2021\Roamer.exe`
- `C:\Program Files\Autodesk\Navisworks Simulate 2021\Roamer.exe`

### Ошибка "Файл NWF не найден"
Проверьте правильность пути к файлу NWF и убедитесь, что файл существует.

### Ошибка доступа к папке
Убедитесь, что у вас есть права на запись в указанную папку для выгрузки.

### Таймаут выполнения
Если процесс занимает слишком много времени, увеличьте параметр `-TimeoutMinutes`.

## Логирование

Все действия автоматизации записываются в файл `automation_log.txt` в папке выгрузки. Лог содержит:

- Временные метки всех операций
- Информацию о количестве обработанных тестов
- Детали ошибок (если возникают)
- Статус завершения операций

## Безопасность

- Скрипт не изменяет исходные файлы
- Все изменения применяются только к открытому документу
- Создаются только отчеты и логи
- Автоматическое закрытие Navisworks после завершения

## Поддержка

При возникновении проблем проверьте:
1. Лог файл `automation_log.txt`
2. Консоль отладки Navisworks
3. Права доступа к файлам и папкам
4. Корректность путей к Navisworks
