# Руководство по автоматизации через CMD/VBS

## Обзор

Создано несколько вариантов скриптов автоматизации для работы без PowerShell:

1. **NavisworksAutomation.bat** - Полная автоматизация через CMD
2. **SimpleNavisworksAutomation.bat** - Упрощенная версия
3. **NavisworksAutomation.vbs** - VBScript версия (максимальная совместимость)

## Вариант 1: Полная автоматизация (CMD)

### Файл: `NavisworksAutomation.bat`

**Возможности:**
- Автоматический поиск Navisworks в стандартных путях
- Запуск Navisworks с файлом NWF
- Создание C# скрипта для автоматизации
- Ожидание завершения операций
- Создание HTML отчета
- Подробное логирование

**Использование:**
```cmd
NavisworksAutomation.bat "C:\path\to\file.nwf" "C:\output\folder" [30]
```

**Параметры:**
- `"путь_к_файлу.nwf"` - путь к файлу Navisworks (обязательный)
- `"папка_выгрузки"` - папка для сохранения отчетов (обязательный)
- `[таймаут_в_минутах]` - таймаут ожидания (по умолчанию 30 минут)

**Пример:**
```cmd
NavisworksAutomation.bat "D:\Projects\MyProject.nwf" "D:\Reports" 45
```

## Вариант 2: Упрощенная автоматизация (CMD)

### Файл: `SimpleNavisworksAutomation.bat`

**Возможности:**
- Автоматический поиск Navisworks
- Запуск Navisworks с файлом NWF
- Создание простого HTML отчета с инструкциями
- Базовое логирование

**Использование:**
```cmd
SimpleNavisworksAutomation.bat "C:\path\to\file.nwf" "C:\output\folder"
```

**Особенности:**
- Не требует сложных операций
- Создает инструкции для ручной обработки
- Быстрый запуск и завершение

## Вариант 3: VBScript автоматизация

### Файл: `NavisworksAutomation.vbs`

**Возможности:**
- Максимальная совместимость с Windows
- Работает на всех версиях Windows
- Автоматический поиск Navisworks
- Создание HTML отчета
- Подробное логирование

**Использование:**
```cmd
cscript NavisworksAutomation.vbs "C:\path\to\file.nwf" "C:\output\folder" [30]
```

**Или через двойной клик:**
1. Создайте ярлык на файл `.vbs`
2. В свойствах ярлыка добавьте параметры в поле "Объект"
3. Запустите ярлык

## Поддерживаемые версии Navisworks

Все скрипты автоматически ищут Navisworks в следующих путях:

- `C:\Program Files\Autodesk\Navisworks Manage 2021\Roamer.exe`
- `C:\Program Files\Autodesk\Navisworks Simulate 2021\Roamer.exe`
- `C:\Program Files\Autodesk\Navisworks Manage 2020\Roamer.exe`
- `C:\Program Files\Autodesk\Navisworks Simulate 2020\Roamer.exe`

## Выходные файлы

### Логи:
- `automation_log.txt` - подробный лог выполнения
- `simple_automation_log.txt` - упрощенный лог

### Отчеты:
- `ClashReport_YYYYMMDD_HHMMSS.html` - HTML отчет
- `SimpleReport_YYYYMMDD_HHMMSS.html` - простой отчет с инструкциями

## Устранение неполадок

### Ошибка: "Navisworks не найден"
**Решение:**
1. Проверьте, установлен ли Navisworks
2. Убедитесь, что путь к Navisworks правильный
3. Запустите скрипт от имени администратора

### Ошибка: "Файл NWF не найден"
**Решение:**
1. Проверьте путь к файлу NWF
2. Убедитесь, что файл существует
3. Используйте полные пути к файлам

### Ошибка: "Нет прав доступа к папке"
**Решение:**
1. Создайте папку для выгрузки заранее
2. Запустите скрипт от имени администратора
3. Проверьте права доступа к папке

### Ошибка: "Скрипт не запускается"
**Решение:**
1. Убедитесь, что файл имеет расширение `.bat` или `.vbs`
2. Проверьте, что скрипт не заблокирован антивирусом
3. Запустите из командной строки для просмотра ошибок

## Рекомендации по использованию

### Для автоматической обработки:
Используйте `NavisworksAutomation.bat` - он выполняет полный цикл автоматизации.

### Для ручной обработки:
Используйте `SimpleNavisworksAutomation.bat` - он только открывает файл и создает инструкции.

### Для максимальной совместимости:
Используйте `NavisworksAutomation.vbs` - работает на всех версиях Windows.

## Интеграция с плагином

После запуска любого из скриптов:

1. **Откройте Navisworks** с загруженным файлом
2. **Найдите вкладку "ClashUnionManager"** в ленте
3. **Используйте кнопки плагина:**
   - "Автогруппировка и кластеризация" (MagicWand)
   - "Авто-наименование"
   - "Автоматизация отчетов"

## Примеры использования

### Пакетная обработка нескольких файлов:
```cmd
@echo off
for %%f in (D:\Projects\*.nwf) do (
    echo Обрабатываем: %%f
    NavisworksAutomation.bat "%%f" "D:\Reports\%%~nf" 30
    timeout /t 60 /nobreak >nul
)
```

### Автоматизация с планировщиком задач:
1. Создайте задачу в Планировщике заданий Windows
2. Укажите путь к скрипту и параметры
3. Настройте расписание выполнения

### Интеграция с другими системами:
Скрипты можно вызывать из:
- Python скриптов
- Java приложений
- C# приложений
- Других систем автоматизации

## Безопасность

- Все скрипты создают только отчеты и логи
- Не изменяют исходные файлы
- Не требуют прав администратора (кроме некоторых случаев)
- Можно запускать в изолированной среде

## Поддержка

При возникновении проблем:
1. Проверьте логи в папке выгрузки
2. Запустите скрипт из командной строки для просмотра ошибок
3. Убедитесь, что все пути корректны
4. Проверьте права доступа к файлам и папкам
