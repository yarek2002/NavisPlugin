# Исправления ошибок компиляции

## Исправленные ошибки

### 1. **Рекурсивные шаблоны C# 7.3**
**Проблема**: Использование `switch` выражений (C# 8.0+)
**Решение**: Заменено на традиционный `switch` statement

**Было**:
```csharp
return status.ToLower() switch
{
    "new" => "status-new",
    "active" => "status-active",
    // ...
};
```

**Стало**:
```csharp
switch (status.ToLower())
{
    case "new":
        return "status-new";
    case "active":
        return "status-active";
    // ...
}
```

### 2. **Неоднозначная ссылка на Application**
**Проблема**: Конфликт между `Autodesk.Navisworks.Api.Application` и `System.Windows.Application`
**Решение**: Использование полного имени класса

**Было**:
```csharp
_doc = Application.ActiveDocument;
```

**Стало**:
```csharp
_doc = Autodesk.Navisworks.Api.Application.ActiveDocument;
```

### 3. **Метод ExportReport не найден**
**Проблема**: Метод `DocumentClash.ExportReport()` не существует в API Navisworks
**Решение**: Заменено на собственный HTML генератор

**Было**:
```csharp
_documentClash.ExportReport(filePath);
```

**Стало**:
```csharp
// Используем собственный HTML экспорт
ExportToHtml(filePath);
```
