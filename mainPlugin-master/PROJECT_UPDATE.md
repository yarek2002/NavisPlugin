# Обновление проекта для автоматизации

## Добавленные файлы в проект

В файл проекта `ClashManager/С.M.2021.csproj` добавлены следующие новые файлы:

### Новые C# файлы:
```xml
<Compile Include="Automation\ReportAutomation.cs" />
<Compile Include="Automation\AutomationSettings.cs" />
<Compile Include="Externals\ReportAutomationCmd.cs" />
```

## Структура добавленных файлов:

```
ClashManager/
├── Automation/
│   ├── ReportAutomation.cs          # Основной класс автоматизации
│   └── AutomationSettings.cs        # Настройки автоматизации
└── Externals/
    └── ReportAutomationCmd.cs       # Команда для запуска из интерфейса
```

## Проверка сборки

### 1. Откройте проект в Visual Studio
- Загрузите файл `ClashManager/С.M.2021.csproj`
- Убедитесь, что все файлы отображаются в Solution Explorer

### 2. Проверьте компиляцию
- Выберите конфигурацию **Release**
- Выполните **Build → Build Solution**
- Убедитесь, что нет ошибок компиляции

### 3. Проверьте зависимости
Убедитесь, что в проекте есть все необходимые ссылки:
- `System.Windows.Forms` (для FolderBrowserDialog)
- `System.Xml` (для сериализации настроек)
- Все существующие зависимости Navisworks API

## Результат сборки

После успешной сборки в папке вывода должна появиться обновленная DLL:
- **Debug**: `D:\NavisPlugin\out\Debug\ClashManager.dll`
- **Release**: `bin\Release\ClashManager.dll`

## Установка обновленного плагина

1. **Скопируйте новую DLL** в папку плагинов Navisworks
2. **Перезапустите Navisworks**
3. **Проверьте появление новой кнопки** "Автоматизация отчетов" в ленте

## Тестирование

### Базовый тест:
1. Откройте Navisworks с файлом, содержащим тесты коллизий
2. Найдите вкладку "ClashUnionManager" в ленте
3. Убедитесь, что появилась кнопка "Автоматизация отчетов"
4. Нажмите кнопку и проверьте работу диалога выбора папки

### Тест автоматизации:
1. Выберите папку для выгрузки отчета
2. Подтвердите запуск автоматизации
3. Проверьте создание HTML отчета и лога в указанной папке

## Устранение неполадок

### Ошибка: "Файл не найден"
- Убедитесь, что все файлы созданы в правильных папках
- Проверьте пути в файле проекта

### Ошибка компиляции: "Не найден тип"
- Проверьте using директивы в новых файлах
- Убедитесь, что все зависимости подключены

### Ошибка: "Кнопка не появляется"
- Проверьте, что файл `AddinRibbon.xaml` обновлен
- Убедитесь, что команда добавлена в `CollisionManager.cs`
- Перезапустите Navisworks

## Дополнительные файлы (не входят в проект)

Следующие файлы созданы для справки и не требуются для работы плагина:
- `README_Automation.md` - документация по использованию
- `HTML_Report_Setup.md` - инструкции по настройке HTML отчетов
- `BUILD_INSTRUCTIONS.md` - инструкции по сборке
- `Example_Usage.cs` - примеры использования
- `NavisworksAutomation.ps1` - PowerShell скрипт для внешней автоматизации

Эти файлы можно использовать как справочные материалы или удалить при необходимости.
