# Настройка HTML отчетов в Navisworks

## Подготовка к автоматизации

Перед использованием автоматизации выгрузки HTML отчетов необходимо настроить параметры отчета в Navisworks.

### Шаг 1: Настройка параметров отчета

1. **Откройте Navisworks** с вашим файлом NWF
2. **Перейдите в меню "Вывод"** → **"Отчет"**
3. **В диалоге "Отчет"** настройте следующие параметры:

#### Основные настройки:
- **Формат**: HTML (табличное представление)
- **Путь для сохранения**: укажите папку по умолчанию
- **Имя файла**: оставьте по умолчанию или настройте шаблон

#### Содержимое отчета:
- ✅ **Включить сводную информацию**
- ✅ **Включить детальную информацию по тестам**
- ✅ **Включить информацию о группах**
- ✅ **Включить информацию о результатах**
- ✅ **Включить изображения** (если нужно)
- ✅ **Включить CSS стили**

#### Дополнительные настройки:
- **Кодировка**: UTF-8
- **Язык**: Русский
- **Формат даты**: DD.MM.YYYY HH:MM:SS

### Шаг 2: Сохранение настроек

1. **Нажмите "Сохранить настройки"** в диалоге отчета
2. **Укажите имя файла настроек** (например, "ClashReportSettings.xml")
3. **Сохраните в папку** с вашим проектом

### Шаг 3: Применение настроек к файлу

1. **В диалоге отчета** нажмите "Применить"
2. **Убедитесь, что настройки сохранились** в файле NWF
3. **Закройте диалог отчета**

## Использование в автоматизации

### Автоматическое использование настроек

При использовании автоматизации с параметром `UseNavisworksReportSettings = true`:

```csharp
var settings = new AutomationSettings
{
    ReportFormat = ReportFormat.HTML,
    UseNavisworksReportSettings = true, // Использует собственный HTML экспорт
    IncludeCssInHtml = true,
    IncludeImagesInHtml = true
};
```

Система автоматически:
1. **Создает HTML отчет** с табличным представлением
2. **Применяет CSS стили** для красивого оформления
3. **Сохраняет отчет** в указанную папку

**Примечание**: Встроенный метод экспорта отчетов Navisworks недоступен через API, поэтому используется собственный HTML генератор с профессиональным дизайном.

### Ручное управление настройками

Если нужно переопределить настройки:

```csharp
var settings = new AutomationSettings
{
    ReportFormat = ReportFormat.HTML,
    UseNavisworksReportSettings = false, // Использует собственные настройки
    IncludeCssInHtml = true,
    IncludeImagesInHtml = true,
    IncludeDetailedInfo = true
};
```

## Структура HTML отчета

### Создаваемый HTML файл содержит:

1. **Заголовок отчета**:
   - Название проекта
   - Дата и время создания
   - Путь к исходному файлу

2. **Сводная таблица**:
   - Общее количество тестов
   - Общее количество групп
   - Общее количество результатов

3. **Детальные таблицы по тестам**:
   - Название теста
   - Список групп с их статусами
   - Количество результатов в каждой группе
   - GUID групп для идентификации

4. **CSS стили**:
   - Современный дизайн
   - Цветовое кодирование статусов
   - Адаптивная верстка
   - Печатные стили

### Цветовое кодирование статусов:

- **New** (Новый): Красный (#e74c3c)
- **Active** (Активный): Оранжевый (#f39c12)
- **Reviewed** (Проверен): Зеленый (#27ae60)
- **Approved** (Одобрен): Фиолетовый (#8e44ad)
- **Resolved** (Решен): Серый (#95a5a6)

## Устранение неполадок

### Проблема: Настройки не применяются

**Решение**:
1. Убедитесь, что настройки сохранены в файле NWF
2. Проверьте права доступа к файлу
3. Перезапустите Navisworks

### Проблема: HTML отчет не создается

**Решение**:
1. Проверьте путь для сохранения
2. Убедитесь, что папка существует
3. Проверьте права на запись в папку

### Проблема: Отчет создается без стилей

**Решение**:
1. Установите `IncludeCssInHtml = true`
2. Проверьте настройки в Navisworks
3. Убедитесь, что используется HTML формат

### Проблема: Изображения не отображаются

**Решение**:
1. Установите `IncludeImagesInHtml = true`
2. Проверьте настройки изображений в Navisworks
3. Убедитесь, что изображения сохранены в той же папке

## Дополнительные возможности

### Кастомизация CSS

Вы можете создать собственный CSS файл и подключить его к отчету:

```csharp
var settings = new AutomationSettings
{
    ReportFormat = ReportFormat.HTML,
    UseNavisworksReportSettings = false,
    ReportTemplatePath = @"C:\Templates\CustomReport.css"
};
```

### Интеграция с другими системами

HTML отчеты можно:
- **Открывать в браузере** для просмотра
- **Импортировать в SharePoint** для совместной работы
- **Конвертировать в PDF** для архивирования
- **Интегрировать с BI системами** для анализа

### Автоматическая отправка отчетов

Можно настроить автоматическую отправку отчетов по email:

```csharp
// После создания отчета
var emailService = new EmailService();
emailService.SendReport(filePath, recipients);
```

## Примеры использования

### Базовое использование

```csharp
var automation = new ReportAutomation(outputPath);
automation.ExecuteFullAutomation();
```

### С настройками HTML

```csharp
var settings = new AutomationSettings
{
    ReportFormat = ReportFormat.HTML,
    UseNavisworksReportSettings = true
};
var automation = new ReportAutomation(outputPath, settings);
automation.ExecuteFullAutomation();
```
