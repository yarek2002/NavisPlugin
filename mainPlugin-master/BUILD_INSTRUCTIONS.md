# Инструкции по сборке и установке автоматизации

## Обзор изменений

Добавлены следующие файлы и изменения для автоматизации выгрузки отчетов:

### Новые файлы:
1. `ClashManager/Automation/ReportAutomation.cs` - основной класс автоматизации
2. `ClashManager/Automation/AutomationSettings.cs` - класс настроек
3. `ClashManager/Externals/ReportAutomationCmd.cs` - команда для запуска из интерфейса
4. `NavisworksAutomation.ps1` - PowerShell скрипт для внешней автоматизации
5. `README_Automation.md` - документация по использованию
6. `Example_Usage.cs` - примеры использования
7. `BUILD_INSTRUCTIONS.md` - данный файл

### Измененные файлы:
1. `ClashManager/CollisionManager.cs` - добавлена команда ReportAutomation
2. `ClashManager/AddinRibbon.xaml` - добавлена кнопка автоматизации

## Шаги по сборке

### 1. Добавление файлов в проект

Добавьте новые файлы в ваш проект Visual Studio:

```
ClashManager/
├── Automation/
│   ├── ReportAutomation.cs
│   └── AutomationSettings.cs
└── Externals/
    └── ReportAutomationCmd.cs
```

### 2. Обновление проекта

1. Откройте файл проекта `.csproj`
2. Убедитесь, что все новые файлы включены в компиляцию:

```xml
<ItemGroup>
  <Compile Include="Automation\ReportAutomation.cs" />
  <Compile Include="Automation\AutomationSettings.cs" />
  <Compile Include="Externals\ReportAutomationCmd.cs" />
</ItemGroup>
```

### 3. Проверка зависимостей

Убедитесь, что в проекте есть ссылки на:
- `System.Windows.Forms` (для FolderBrowserDialog)
- `System.Xml` (для сериализации настроек)
- Все существующие зависимости Navisworks API

### 4. Сборка проекта

1. Откройте проект в Visual Studio
2. Выберите конфигурацию Release
3. Соберите решение (Build → Build Solution)
4. Убедитесь, что нет ошибок компиляции

### 5. Установка плагина

1. Скопируйте собранную DLL в папку плагинов Navisworks
2. Перезапустите Navisworks
3. Проверьте, что появилась новая кнопка "Автоматизация отчетов"

## Тестирование

### Тест 1: Базовая функциональность
1. Откройте Navisworks с файлом, содержащим тесты коллизий
2. Нажмите кнопку "Автоматизация отчетов"
3. Выберите папку для выгрузки
4. Подтвердите запуск
5. Проверьте, что созданы файлы отчета и лога

### Тест 2: Разные форматы отчетов
1. Создайте настройки с разными форматами (TXT, CSV, XML)
2. Запустите автоматизацию с каждым форматом
3. Проверьте корректность созданных файлов

### Тест 3: PowerShell скрипт
1. Откройте PowerShell от имени администратора
2. Запустите скрипт с параметрами:
```powershell
.\NavisworksAutomation.ps1 -NwfFilePath "C:\path\to\file.nwf" -OutputFolderPath "C:\output\folder"
```
3. Проверьте результат

## Устранение неполадок

### Ошибка компиляции: "Не найден тип или пространство имен"
- Убедитесь, что все using директивы корректны
- Проверьте, что все зависимости подключены

### Ошибка: "Кнопка не появляется в ленте"
- Проверьте, что файл AddinRibbon.xaml обновлен
- Убедитесь, что команда добавлена в CollisionManager.cs
- Перезапустите Navisworks

### Ошибка: "Не удается найти файл"
- Проверьте пути к файлам в коде
- Убедитесь, что папки существуют или создаются автоматически

### Ошибка PowerShell: "Выполнение скриптов отключено"
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
